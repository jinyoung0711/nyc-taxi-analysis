### 행렬

- 행렬(matrix)은 벡터를 원소로 가지는 2차원 배열
- 행렬은 행(row)과 열(column)이라는 인덱스(index)를 가진다.
- 행렬의 특정 행(열)을 고정하면 행(열)벡터라 부른다.

$$
X=\begin{bmatrix}1&-2&3\\7&5&0\\-2&-1&2\end{bmatrix}
$$

```python
X = np.array([[1, -2, 3],
							[7, 5, 0],
							[-2, -1, 2]])
```

$$
X=\begin{bmatrix}X_1\\X_2\\.\\X_n\end{bmatrix}=\begin{bmatrix}x_{11}&x_{12}&...&x_{1m}\\x_{21}&x_{22}&...&x_{2m}\\.&.&.&.\\x_{n1}&x_{n2}&...&x_{nm}\end{bmatrix}
$$

```python
X = np.array([1, -2, 3],
						 [7, 5, 0],
					 	 [-2, -1, 2]])

# 역행렬
np.linalg.inv(X) 

# 항등행렬과 유사
X @ np.linalg.inv(X)
```
