## 1. 앙상블 러닝(Ensemble learning)이란?

### 1.1 배경

![각각의 색은 algorithm, x축은 datasest, y축은 error를 의미](%앙상블/Untitled.png)

각각의 색은 algorithm, x축은 datasest, y축은 error를 의미

단일 알고리즘보다 적당한 알고리즘들을 여러개 조합해서 좋은 성능을 기대하는 기법

### 1.2 앙상블 러닝의 정의

- 여러 개의 결정 트리(Decision Tree)를 결합하여 하나의 결정 트리보다 더 좋은 성능을 내는 머신러닝 기법
- 앙상블 학습의 핵심은 여러 개의 여러 개의 약 분류기(Weak Classifier)를 결합하여 강 분류기(Strong Classifier)를 만드는 과정
- 여러 개의 단일 모델들의 평균치를 내거나, 투표를 해서 다수결에 의한 결정을 하는 등 여러 모델들의 집단 지성을 활용하여 더 나은 결과를 도출해 내는 것에 주 목적이 있음.

![Untitled](%앙상블/Untitled%201.png)

여러 개의 분류기를 학습한 후, 약 분류기에 가중치를 주어 강 분류기를 만드는 학습

1. 성능을 분산시키기 때문에 과적합(Overfitting) 감소 효과
2. 개별 모델 성능이 잘 안나올 때 앙상블 학습을 이용하면 성능이 향상될 수 있음.

### 1.3 앙상블 러닝의 기법

1. **Bagging - Boostrap Aggregation (샘플을 다양하게 생성)**

![Untitled](%앙상블/Untitled%202.png)

Bagging은 Bootstrap Aggregation의 약자. 훈련세트에서 중복을 허용하여 샘플링 하는 방식.

모두 같은 유형의 알고리즘 기반의 분류기를 사용한다는 특징이 존재.

Overfitting 방지에 효과적.

대표적인 알고리즘으로는 RandomForest Algorithm

cf) 훈련세트에서 중복을 허용하지 않고 샘플링 하는 방식을 페이스팅(Pasting)이라고 함. 

1. Voting(투표) - 투표를 통해 결과 도출
- 투표를 통해 결정하는 방식. Voting은 Bagging과 같은 투표방식이라는 점에서 유사하지만, 다음과 같은 큰 차이점이 존재
    - Voting은 다른 알고리즘 model을 조합해서 사용
    - Bagging은 같은 알고리즘 내에서 다른 Sample 조합을 사용
- Voting은 서로 다른 알고리즘이 도출해 낸 결과물에 대하여 최종 투표하는 방식
- hard vote와 soft vote로 나뉨.
- hard vote는 결과물에 대한 최종 값을 투표해서 결정하고, soft vote는 최종 결과물이 나올 확률 값을 다 더해서 최종 결과물에 대한 각각의 확률을 구한 뒤 최종값을 도출.

![Voting과 Bagging의 차이](%앙상블/Untitled%203.png)

Voting과 Bagging의 차이

1. Boosting - 이전 오차를 보완하며 가중치 부여 (예측도가 높음)

![Untitled](%앙상블/Untitled%204.png)

여러개의 분류기가 순차적으로 학습을 수행하는 것.

이전 분류기가 예측을 하지 못한 데이터에 대해 올바르게 예측할 수 있도록 가중치를 부여하며 학습과 예측을 진행하는 방식

대표적인 부스팅 모델로는 XGBoost, LightGBM, CatBoost 

Bagging에 비해 성능은 잘 나오지만, 순차적으로 진행하기에 속도가 느리고 Overfitting 발생 가능하다는 단점 존재.

1. Stacking - 여러 모델을 기반으로 meta 모델

![Untitled](%앙상블/Untitled%206.png)

성능 향상. Overfitting 발생 가능.
